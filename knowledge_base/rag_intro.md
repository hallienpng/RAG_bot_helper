# Что такое RAG

RAG (Retrieval-Augmented Generation, генерация с дополнением извлечённой информацией) — подход, при котором языковая модель отвечает на вопрос не только по своим знаниям, а по фрагментам документов, найденным в базе знаний.

Работа RAG-системы состоит из трёх шагов. Сначала документы разбиваются на фрагменты (чанки) и индексируются. Затем по вопросу пользователя находятся самые похожие фрагменты. Наконец, найденные фрагменты вместе с вопросом передаются языковой модели, и она формулирует ответ.

Главное преимущество RAG — модель опирается на актуальные и проверяемые данные, поэтому меньше выдумывает (галлюцинирует) и может указать источник ответа. Чтобы обновить знания бота, достаточно обновить документы, переобучать модель не нужно.

# Поиск релевантных фрагментов

В этом проекте для поиска используется TF-IDF по символьным n-граммам и косинусное сходство. Такой поиск не требует GPU и внешних сервисов и устойчив к падежам и окончаниям русских слов.

Более продвинутый вариант — векторные эмбеддинги (например, sentence-transformers) и векторная база данных (Chroma, FAISS, Qdrant). Эмбеддинги лучше понимают смысл: находят фрагменты, где те же идеи выражены другими словами.
