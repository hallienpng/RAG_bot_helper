# Работа с базой знаний RAG_bot_helper

База знаний — папка `knowledge_base/` в корне проекта. Бот индексирует файлы `.txt`, `.md`, `.pdf` (в том числе во вложенных папках).

## Добавление документа

1. Положи файл в `knowledge_base/` (или в тематическую подпапку). Имя файла — латиницей, без пробелов: оно показывается пользователю как источник.
2. Если исходник в другом формате (.docx, .html), сконвертируй его в `.md`, сохранив заголовки `#`/`##`: по заголовкам документ режется на фрагменты, и каждый раздел остаётся цельным.
3. Не клади секреты и персональные данные: содержимое базы попадает в запросы к LLM.

## Проверка

Сформулируй 2–3 вопроса, ответ на которые есть в новом документе, и прогони их без LLM:

```bash
source venv/bin/activate
printf 'ВОПРОС 1\nВОПРОС 2\nexit\n' | LLM_API_KEY= python cli.py
```

Новый файл должен оказаться среди источников в квадратных скобках с релевантностью заметно выше остальных. Если нет:
- раздел слишком длинный — разбей его заголовками на подразделы;
- в вопросе другие слова, чем в тексте — добавь в документ формулировки, которыми спрашивают пользователи (раздел FAQ);
- поменяй `CHUNK_SIZE` / `TOP_K` / `MIN_SCORE` в `.env`.

В конце запусти `python -m pytest -q` и напомни, что запущенному Telegram-боту нужна команда `/reload`.
